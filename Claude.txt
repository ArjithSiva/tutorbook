## Now, the Atlas walkthrough (so `MONGO_URI` is real)

1. Go to **mongodb.com/cloud/atlas/register** and sign up (free).
2. Click **Build a Database** → choose the **M0 Free** tier → pick any cloud/region → **Create**.
3. **Database Access** (left sidebar) → **Add New Database User** → set a username/password, save them somewhere.
4. **Network Access** → **Add IP Address** → for now, choose **Allow Access from Anywhere** (`0.0.0.0/0`) — fine for development, you'd lock this down for production.
5. Go back to your cluster → **Connect** → **Drivers** → copy the connection string. It looks like:
   ```
   mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/
   ```
6. Paste that into `backend/.env` as `MONGO_URI`, swap in your real username/password, and add a database name before the `?`, e.g.:
   ```
   MONGO_URI=mongodb+srv://myuser:mypass@cluster0.xxxxx.mongodb.net/tutorbook?retryWrites=true&w=majority
   ```

## Step 2 — Deploy the backend on Render

1. Go to **render.com** → sign up (no credit card needed) → **New +** → **Web Service**
2. Connect your GitHub account, select the `tutorbook` repo
3. Set:
   - **Root Directory:** `backend`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
4. Under **Environment**, add these variables (same as your local `.env`):
   - `MONGO_URI` → your Atlas connection string
   - `JWT_SECRET` → your random secret
   - `CLIENT_URL` → leave as `http://localhost:5173` for now, we'll fix it in Step 4
5. Click **Create Web Service**. Render will build and deploy — you'll get a URL like `https://tutorbook-api.onrender.com`
6. Test it: visit `https://tutorbook-api.onrender.com/api/health` — you should see `{"status":"ok",...}`

## Step 3 — Deploy the frontend on Vercel

1. Go to **vercel.com** → sign up → **Add New** → **Project**
2. Import the same `tutorbook` GitHub repo
3. Set **Root Directory** to `frontend` (Vercel should auto-detect Vite)
4. Under **Environment Variables**, add:
   - `VITE_API_URL` → `https://tutorbook-api.onrender.com/api` (your Render URL + `/api`)
5. Click **Deploy**. You'll get a URL like `https://tutorbook-yourname.vercel.app`

## Step 4 — Connect the two (fix CORS)

Go back to Render → your web service → **Environment** → update:
```
CLIENT_URL=https://tutorbook-yourname.vercel.app
```
Save — Render will auto-redeploy. This lets your backend accept requests from your live frontend (right now it only trusts `localhost`).
